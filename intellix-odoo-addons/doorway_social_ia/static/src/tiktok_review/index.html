Where the integration actually lives

TikTok Login Kit and the Content Posting API (Direct Post) are built into the Intellix CRM web application. The website URL declared in the developer portal is https://intellixcrm.com — the same domain shown in this demo.

Product — Login Kit

Connect a TikTok account per brand

A publisher clicks Connect TikTok in Intellix. The web app sends them to TikTok OAuth v2, then stores the token on that brand’s social account (one authorization per brand).

Scopes requested — only what the app uses

Every selected scope is demonstrated

user.info.basic

Login Kit reads the connected creator’s open_id, display name and username after the token exchange, then labels the Intellix account (e.g. @coinsmarrakech).

video.publish

Content Posting API Direct Post uploads an MP4 and publishes it. In sandbox the privacy status is SELF_ONLY.

Unused products and scopes were not added. Share Kit and Display API are not selected.

Product — Content Posting API

Direct Post · FILE_UPLOAD

  1. POST /v2/post/publish/creator_info/query/ — creator capabilities
  2. POST /v2/post/publish/video/init/ — Direct Post, source FILE_UPLOAD
  3. Chunked PUT of the MP4 to the returned upload URL
  4. Sandbox privacy: SELF_ONLY

Posts stay private until the app passes Production audit. No unused kit is called.

Async status — required for Direct Post

Poll until PUBLISH_COMPLETE

  1. POST /v2/post/publish/status/fetch/
  2. PROCESSING_UPLOAD → PROCESSING_DOWNLOAD → PUBLISH_COMPLETE
  3. Intellix marks the calendar post published and consumes the credit only then
